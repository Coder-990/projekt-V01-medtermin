# Testovi i sigurnosne promjene — kratki podsjetnik za obranu

Usporedba s izvornim commitom `e72c770`: izvorni funkcionalni testovi ostali su neizmijenjeni; novi sigurnosni testovi nalaze se u `sigurnost`. Poveznice vode na konkretne testove i promijenjeni Java kod. U pregledu dokumenta klikni poveznicu; u uređivaču koristi Ctrl+klik. Oznaka `#L` otvara navedeni redak u IntelliJ IDEA-i.

## Sigurnosni popravci: napad, promjena i test

Prati redom [demonstraciju obrane](obrana-projekta.md#demonstracija--prati-redom). Usporedi staru verziju na 8081 s popravljenom na 8080; poveznice ispod vode na popravljeni kod i testove.

### Redoslijed demonstracije

- **Lozinka u logu:** Prije je cijeli zahtjev za prijavu, uključujući lozinku, završavao u logu. Sada se zapisuje samo događaj: [kod: log prijave](../src/main/java/hr/span/akademija/medtermin/platforma/KorisnikService.java#L69); [test loga](../src/test/java/hr/span/akademija/medtermin/sigurnost/AutentikacijaSigurnostTest.java#L62).
- **Tuđi nalaz — IDOR:** Nevaljani format prije je zaobišao provjeru vlasništva. Sada vlasnika provjeravamo prije obrade formata: [kod: vlasništvo nalaza](../src/main/java/hr/span/akademija/medtermin/nalazi/NalazController.java#L85); [novi test](../src/test/java/hr/span/akademija/medtermin/sigurnost/SigurnostHttpTest.java#L12).
- **SQL injekcija pri sortiranju liječnika:** Prije se korisnički `sort` izravno dodavao u SQL, pa je mogao biti SQL izraz. Sada se vrijednosti mapiraju na dopuštene stupce i smjerove: [kod: dopušteni stupci](../src/main/java/hr/span/akademija/medtermin/lijecnici/LijecnikController.java#L47); [test SQL izraza](../src/test/java/hr/span/akademija/medtermin/sigurnost/SigurnosniRegresijskiTest.java#L19).
- **Preširok CORS:** Prije je nepoznati HTTP(S) origin dobivao dopuštenje uz vjerodajnice, što može omogućiti čitanje odgovora ovisno o pregledniku i kolačićima. Sada se provjerava konfigurirana lista: [kod: provjera origina](../src/main/java/hr/span/akademija/medtermin/platforma/CorsFilter.java#L61); [test nepoznatog origina](../src/test/java/hr/span/akademija/medtermin/sigurnost/SigurnostHttpTest.java#L18).
- **Prijava liječnika:** Provjera identiteta i uloge pokazuje da prijava i dalje radi. [Kod prijave](../src/main/java/hr/span/akademija/medtermin/platforma/AuthController.java#L43); [postojeći funkcionalni test prijave](../src/test/java/hr/span/akademija/medtermin/funkcionalno/AutentikacijaFunkcionalniTest.java#L25).
- **YAML deserijalizacija:** Prije je nepouzdani YAML mogao stvoriti proizvoljni Java objekt i pokrenuti konstruktor. Sada `SafeConstructor` dopušta podatkovne tipove: [kod: YAML parser](../src/main/java/hr/span/akademija/medtermin/platforma/PostavkeController.java#L66); [test bezopasnog konstruktora](../src/test/java/hr/span/akademija/medtermin/sigurnost/YamlDeserijalizacijaTest.java#L16).
- **Ponovna uporaba reset tokena:** Prije se isti token mogao koristiti više puta. Sada vrijedi ograničeno vrijeme i označava se iskorištenim: [kod: atomsko trošenje](../src/main/java/hr/span/akademija/medtermin/platforma/ResetLozinkeService.java#L67); [test jednokratnosti](../src/test/java/hr/span/akademija/medtermin/sigurnost/AutentikacijaSigurnostTest.java#L45).

Lozinka u logu i reset token su dodatni primjeri ako ostane vremena; prijava na početku pokazuje i zapis u terminalu stare verzije.

### Ostale promjene

- **Tuđa datoteka / path traversal:** Ime datoteke prije se provjeravalo prema podnizu korisničkog imena; napadač je mogao pokušati prijeći izvan mape ili pročitati tuđi nalaz. Sada se provjeravaju zapis i vlasnik te se datoteka sigurno otvara bez praćenja poveznica: [kod: sigurno otvaranje](../src/main/java/hr/span/akademija/medtermin/nalazi/NalazController.java#L133); [test putanje i poveznice](../src/test/java/hr/span/akademija/medtermin/sigurnost/SigurnosniRegresijskiTest.java#L38).
- **Predvidljivi reset token:** Prije je token bio MD5 korisničkog imena i datuma, pa se mogao pogoditi i iskoristiti za preuzimanje računa. Sada se generira slučajno i sprema se njegov SHA-256 sažetak: [kod: stvaranje tokena](../src/main/java/hr/span/akademija/medtermin/platforma/ResetLozinkeService.java#L45); [test stare formule](../src/test/java/hr/span/akademija/medtermin/sigurnost/AutentikacijaSigurnostTest.java#L36).
- **Slabe lozinke u bazi:** Prije se koristio brzi SHA-256 bez soli; kod curenja baze lakše je pogađati lozinke. Sada nove lozinke koriste BCrypt, a stare se pri prijavi mogu migrirati: [kod: BCrypt](../src/main/java/hr/span/akademija/medtermin/platforma/LozinkaHasher.java#L17); [test pohrane](../src/test/java/hr/span/akademija/medtermin/sigurnost/AutentikacijaSigurnostTest.java#L55).
- **Otvoreno preusmjeravanje:** Prije je `returnUrl` mogao odvesti korisnika na vanjsku stranicu za phishing. Sada se dopuštaju provjerene lokalne putanje: [kod: odredište](../src/main/java/hr/span/akademija/medtermin/platforma/PrijavaController.java#L130); [test preusmjeravanja](../src/test/java/hr/span/akademija/medtermin/sigurnost/SigurnosniRegresijskiTest.java#L29).
- **Krađa ili zlouporaba sesije:** Tokeni prije nisu imali rok ni opoziv. Dodani su istek, odjava i opoziv sesija pri promjeni lozinke: [kod: sesije](../src/main/java/hr/span/akademija/medtermin/platforma/TokenStore.java#L23); [test isteka i opoziva](../src/test/java/hr/span/akademija/medtermin/sigurnost/platforma/PlatformaJedinicniTest.java#L134).
- **CSRF i pogađanje lozinke:** Zahtjevi s kolačićem provjeravaju pouzdani origin, a broj pokušaja prijave ograničen je po IP adresi: [kod: CSRF](../src/main/java/hr/span/akademija/medtermin/platforma/AuthFilter.java#L48) i [kod: ograničenje](../src/main/java/hr/span/akademija/medtermin/platforma/OgranicenjeAutentikacijeFilter.java#L38); [test CSRF-a](../src/test/java/hr/span/akademija/medtermin/sigurnost/SigurnostHttpTest.java#L34) i [test ograničenja](../src/test/java/hr/span/akademija/medtermin/sigurnost/OgranicenjeAutentikacijeTest.java#L10).
- **Osobni podaci u logu rezervacije:** Prije je cijeli zahtjev otkrivao OIB i napomenu; sada se zapisuje samo broj termina: [kod: log rezervacije](../src/main/java/hr/span/akademija/medtermin/rezervacije/RezervacijaService.java#L77); [postojeći test kreiranja rezervacije](../src/test/java/hr/span/akademija/medtermin/funkcionalno/RezervacijeFunkcionalniTest.java#L78) — provjerava funkcionalnost, ne sadržaj loga.
